getLawGraph - закон + его связи с другими актами, контекст для GraphRAG (graphs-service);

addLawToUserGraph - добавить закон в граф пользователя (graphs-service);
findAndAddRelatedLawsToGraph - семантич. поиск BGE-M3 + реранкер, топ-K в граф (graphs-service);
findArticle - статья по номеру; номер извлекается NER из запроса (graphs-service);
searchArticles - гибридный поиск по статьям: BGE-M3 + BM25 + реранкер (graphs-service);
linkDocumentClauseToArticle - связать пункт документа со статьёй: cosine BGE-M3 + проверка cross-encoder (graphs-service);
flagArticleConflict - конфликт статья-статья, подтверждённый NLI (contradiction) (situation-service);

linkDocumentToLawsInGraph - законы для документа: эмбеддинг документа + реранкер, связь в графе (GraphActionService);
classifyIntent - новый: интент + профиль юриста, fine-tuned xlm-roberta;
